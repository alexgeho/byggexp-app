# ByggExp app — дизайн-система

Одно правило на всё приложение. Значения — только из токенов, своих чисел в экранах нет.

## 1. Токены (одно место)

| Что                                              | Где                                             | Значение                       |
| ------------------------------------------------ | ----------------------------------------------- | ------------------------------ |
| Радиус карточки / группы полей / карточки списка | `radius.card` (`src/theme/tokens.js`)           | **16**                         |
| Радиус кнопки / поля / чипа                      | `radius.control`                                | полный (pill)                  |
| Радиус шторки (bottom sheet)                     | `radius.sheet`                                  | 24                             |
| Высота кнопки и однострочного поля               | `size.control`                                  | **48**                         |
| Круглая кнопка в шапке (назад / ✓)               | `size.headerButton`                             | 44                             |
| Рамка                                            | `size.border`                                   | 1                              |
| Боковые поля формы                               | `layout.formGutter` (`src/theme/spacing.js`)    | 16                             |
| Шапка → контент, карточка ↔ карточка             | `layout.headerToContent`, `layout.betweenCards` | 12                             |
| Между группами в форме                           | `betweenCards × 2`                              | 24                             |
| Внутри строки (padding)                          | FieldRow                                        | 16 по бокам, 12 сверху/снизу   |
| Шкала отступов                                   | `space`                                         | 4 · 8 · 12 · 16 · 20 · 24 · 32 |

**Цвета** — `theme.content.*` (светлая = iOS 1:1, тёмная — свои значения):
фон `#F2F2F7`, карточка `#FFFFFF`, текст `#000`, подпись `#6C6C70`, плейсхолдер `#C7C7CC`, разделитель `#C6C6C8`, рамка `#E5E5EA`. Один акцент — `theme.colors.primary` (кнопка, ✓, выбранный чип). Серый — только для второстепенного.

**Шрифт** — системный (SF). DM Sans в формах больше не используется.

| Роль                        | Размер / вес                                  |
| --------------------------- | --------------------------------------------- |
| Заголовок экрана            | 17 / 600                                      |
| Значение поля, текст кнопки | 16 / 400 и 15 / 600                           |
| Подпись поля                | 13 / 600, `#6C6C70`                           |
| Заголовок секции            | 13 / 700, UPPERCASE, на линии текста карточки |

## 2. Общие компоненты (`src/components/common`)

| Компонент                 | Что делает                                                                                                                                                                                                        |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ui/FormHeader`           | Шапка формы: круглая «назад», заголовок по центру, круглая ✓                                                                                                                                                      |
| `FieldRow/FieldCard`      | Белая карточка-группа, радиус 16, без рамки                                                                                                                                                                       |
| `FieldRow/FieldRow`       | Строка 62pt: `input` / `select` / `readonly` / `toggle`, своя разметка через `children` (чипы). `floating` — подпись внутри пустого поля, над значением после ввода. Подпись никогда не дублируется плейсхолдером |
| `ui/Button`               | `primary` (залитая), `outline` (рамка 1px), `secondary`. Все с рамкой 1px (у залитой прозрачная), поэтому пара всегда одной высоты 48                                                                             |
| `ui/ChoiceChips`          | Выбор одного варианта: чипы-пилюли 36pt, выбранный залит акцентом                                                                                                                                                 |
| `ui/SectionTitle`         | Заголовок секции; `inset` — на линии текста внутри карточки                                                                                                                                                       |
| `ui/HeaderCheckButton`    | Круглая ✓ 44 (сохранить)                                                                                                                                                                                          |
| `ListCard` / `cardStyles` | Карточка списка, радиус 16                                                                                                                                                                                        |

## 3. Правила экрана-формы

1. Шапка (FormHeader) → группы FieldCard → одна главная кнопка внизу (если нужна).
2. Связанные поля — в одной карточке. Между карточками 24, заголовок секции → карточка 12.
3. Все строки одной высоты (62pt): пустая и заполненная не прыгают.
4. Минимум текста: только подпись поля и действие. Без подсказок, пояснительных абзацев, повторов («dagar netto» один раз в подписи, не на каждом чипе).
5. Пара действий: слева `outline`, справа `primary`, одна ширина и высота.
6. Тёмная тема: правки цвета только через `onDark(c, darkValue, "<светлое как было>")`.

## 4. Как проверять

- Симулятор (dev-сборка): `xcrun simctl openurl booted "byggexp://dev-nav/<Screen>"` открывает любой экран, `byggexp://dev-theme/black|blue` переключает тему. Только в `__DEV__`.
- Мерить высоты по скриншоту: строки одной группы должны быть равны (62pt = 146px на скриншоте iPhone 16 при 923px ширины).
