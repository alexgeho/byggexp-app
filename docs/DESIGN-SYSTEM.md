## 3. Правила экрана-формы

0. Эталон — **Skapa projekt**. Любая форма сверяется с ним по пикселям (кнопка ✓ и верх первой карточки на одной высоте).
1. FormScreen → FormHeader → группы FieldCard → одна главная кнопка внизу (если нужна).
2. Связанные поля — в одной карточке. Между карточками 24, заголовок секции → карточка 12.
3. Все строки одной высоты (62pt): пустая и заполненная не прыгают.
4. Минимум текста: только подпись поля и действие. Без подсказок, пояснительных абзацев, повторов («dagar netto» один раз в подписи, не на каждом чипе).
5. Пара действий: слева `outline`, справа `primary`, одна ширина и высота.
6. Тёмная тема: правки цвета только через `onDark(c, darkValue, "<светлое как было>")`.

## 4. Как проверять

- Симулятор (dev-сборка): `xcrun simctl openurl booted "byggexp://dev-nav/<Screen>"` открывает любой экран, `byggexp://dev-theme/black|blue` переключает тему. Только в `__DEV__`.
- Мерить высоты по скриншоту: строки одной группы должны быть равны (62pt = 146px на скриншоте iPhone 16 при 923px ширины).

## 6. Иерархия внимания (экраны-инструменты, эталон — Arbetspass)

Правило директора (2026-10-23): на экране сразу видно, куда смотреть. Не больше 4 уровней, уровень задают размер, контраст и толщина, а не новые цвета. Залитая синяя кнопка — одна на экран.

| Уровень               | Что                                                                      | Как выглядит                                                                                                            |
| --------------------- | ------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| 1 — главное           | часы выбранного дня, одно главное действие (＋ Lägg till timmar / Spara) | часы 19/600 основным цветом (было 22/700, уменьшено 2026-10-25); кнопка залита синим                                    |
| 2 — рабочая зона      | лента недели                                                             | дата 19/500, выбранный день — синяя рамка 1px (не заливка, см. §7), часы под датой                                      |
| 3 — навигация и итоги | месяц, неделя, переключатель дня, итог недели/месяца                     | месяц 19/700 (самый тёмный в навигации); неделя 15/600; стрелки серые, без своих плашек; итоги 17/600, подписи 13 серые |
| 4 — настройки         | Planerad/Manuell/GPS, «Välj period», фильтры админа, «Summera»           | полупрозрачный фон, высота 32–40, текст 13–15 серый; «Summera» — контурная, не залитая                                  |

Нельзя: делать уровень 4 крупнее или темнее уровня 3; ставить вторую залитую синюю кнопку; прятать главное число в серый мелкий текст (было: часы смены 14 серым).

- (2026-10-27) Чипы-выбор рядом с главной кнопкой не красить синим — `ChoiceChips tone="soft"`. Пока на экране нет данных, главное действие одно (напр. «Lägg till artikel»); ✓ в шапке и «Spara» появляются, когда есть что сохранять.
- (2026-10-27) Поле относится к той карточке, о которой оно: дата доставки — в карточке «Leverans», а не рядом с комментарием.

## 7. Календари, часы, цвета информации (правки владельца 2026-10-25)

| Что                                           | Правило                                                                                                                                                 |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |

| Сегодня                                       | синее число даты. Без рамки и плашки (в Schema — синий текст вместо синей пилюли)                                                                       |

## 8. Шторки (bottom sheet)

- Нижняя шторка открывается мягко: `Modal transparent animationType="fade"` + сама шторка в `SheetView` / `SheetPressable` (`components/common/SheetSlideIn`, ease-out 340 мс через `hooks/useSheetEnter`). Фон проявляется, шторка выезжает — экран целиком не «въезжает».
- `animationType="slide"` — только для полноэкранных страниц (выбор роли/языка/проектов, карта, QR).

## 9. Ввод и сохранение

- Ввод дня сохраняется сам через 1 с после изменения; у итога на 2,5 с зелёное «Sparat ✓» (`#45B36B`). Кнопка ✓ остаётся как «готово».
- Пустое поле само не сохраняется (иначе стирает день в 0).
- Экран не прыгает: при тапе в поле не прокручивать вручную к другим элементам — прокрутка к дню один раз при открытии, дальше iOS сама держит поле над клавиатурой.

## 10. Как вносить правки

Каждое замечание владельца по виду/поведению — сразу строкой сюда (в нужный раздел), с датой, и применить во всех местах приложения, где это встречается. Перед сдачей — поиском проверить, что старого варианта нигде не осталось.

## 12. «Intern tid» (2026-10-26)

- Внутренний проект компании (`project.internal`) — время вне объекта клиента, идёт в зарплату, не в счёт.
- Показывается **только** там, где выбирают проект для смены/часов — последней строкой списка, без адреса и статуса, подпись `projects.internalTime`. Везде остальное (Mina projekt, карта, задачи, экономика, счёт, Schema) — скрыт (`projectService` по умолчанию, `{ includeInternal: true }` — только для смены).
- Без геозоны: старт смены не проверяет место.

## 13. Поля дневного отчёта, которые выключил работодатель (2026-10-26)

## 15. Материалы и Fortnox (2026-10-26)

- Проект → вкладка «Material»: заказы проекта карточками (поставщик, бейдж Utkast — янтарный / Skickad — зелёный, строка «N artiklar · дата · комментарий»). Новый заказ — через «+» нижней панели.
- «Ny beställning»: сверху карточка «Leverantör» — тихие чипы поставщиков **одной строкой с горизонтальной прокруткой** до края карточки (`ChoiceChips scroll`; без переноса в несколько строк) (выбран первый; после первой строки — просто текст, сменить нельзя); артикулы в поиске — только этого поставщика. **Иерархия:** пока строк нет, единственное действие — синяя «Lägg till artikel» (✓ в шапке и «Spara utkast» скрыты); после первой строки «Lägg till artikel» становится outline, появляются ✓ и «Spara utkast». Поиск без цен (работнику); один заказ = один поставщик. Строка: название + «art.nr · enhet», справа − / количество / + (на 1 вместо − корзина). Leveransdatum (было «Önskat datum») — строка «подпись слева, дата справа», последняя в карточке Leverans (по умолчанию завтра), Kommentar. Работник сохраняет только черновик.
- Цены в заказе — только админу (API работнику их не отдаёт): в строке «art.nr · enhet · сумма строки», внизу карточки строк «Summa» справа; в списке заказов админу сумма в целых кронах вместо комментария. Админ правит любой черновик, работник — только свой.
- Вкладки проекта: Uppgifter, Dokument, Arbetare, **Material (4-я)**, Verktyg, Foton, Ekonomi.
- «Leverantörer» (Meny → Ekonomi, только companyAdmin/superadmin) — зеркало веб-админки: карточки «название / e-mail · kundnummer», «+» → форма (Namn, E-post för beställningar, Kundnummer), тап → правка (название не меняется), красная текстовая «Ta bort» с подтверждением или свайп = скрыть из новых заказов (артикулы и заказы остаются).
- Карточки заказа по порядку: Leverantör → строки + «Lägg till artikel» → **Leverans** (чипы, адрес, «Leveransdatum» — дата доставки живёт в карточке доставки, не отдельно) → Kommentar отдельной карточкой.
- Leverans: чипы «Projektets adress» / «Annan adress» — **тихие** (`ChoiceChips tone="soft"`: выбранный — серая заливка inputSurface, чёрный текст; синий не использовать — это не главное действие); ниже — адрес проекта текстом или поле «Adress».
- Уведомления заказов: новый черновик → админам, «Beställning #N skickad» → автору; тап открывает заказ; внизу заказа из пуша серая «Stäng av aviseringar» (bell-off), включить — Aviseringar → «Materialbeställningar».
- Заказ со связанным счётом оптовика — серой строкой «Fakturerad #nr» на карточке и в заголовке поставщика; в «Beställt material» уже не входит (считает бэк).
- Ekonomi проекта: строка «Beställt material» (все заказы по закупочной цене, сразу с момента заказа) входит в Total kostnad.
- Leverantörsfakturor: серая третья строка карточки — «Fakturerad #nr» (расход перевыставлен клиенту) или «Från Fortnox» (импорт); fortnox-счёт только для чтения: тап ничего не открывает, свайп-удаление → «Importerad från Fortnox – ändra eller ta bort den där».
- Счета: «Skickad till Fortnox» серой третьей строкой карточки (не в строке срока — иначе сумма уезжает под ⋮), только при fortnoxStatus = sent (ошибка в приложении не показывается), без значков и цвета.
- Заказ: свой черновик открывается на правку (− / + / Lägg till artikel / дата / комментарий, красная текстовая «Ta bort beställning» с подтверждением); отправленный или чужой — только просмотр, без кнопок.
