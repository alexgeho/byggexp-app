# Отступы — одно правило на всё приложение

Токены: `src/theme/spacing.js`. Любой экран берёт **роль**, а не число.

## Шкала

8-точечная сетка (Material + Apple HIG), с половинным шагом 4 там, где 8 мало,
а 16 много:

`4 · 8 · 12 · 16 · 20 · 24 · 32`

## Роли

| Роль                     | Значение | Где                                                                                                                      |
| ------------------------ | -------- | ------------------------------------------------------------------------------------------------------------------------ |
| `layout.screenGutter`    | **20**   | боковые поля страницы → по ним края карточек                                                                             |
| `layout.cardPadding`     | **20**   | внутренний отступ карточки; текст карточки начинается на 40 от края экрана                                               |
| `layout.betweenCards`    | **12**   | карточка↔карточка, заголовок списка→первая карточка, **над и под** заголовком секции, ряд фильтров→список, пилюли→список |
| `layout.headerToContent` | **12**   | шапка экрана → первый элемент под ней                                                                                    |
| `layout.insideCard`      | **8**    | между строками внутри одной карточки                                                                                     |
| `layout.listBottom`      | **140**  | нижний отступ прокрутки, чтобы плавающий бар не перекрывал последнюю карточку                                            |

## Правила

1. **Никаких своих чисел в экранах.** Если нужен отступ — берём роль из
   `layout`. Было наоборот: список задач добавлял свои 12, экономика — 20,
   карточка онбординга — 16, цветная тема — 14, оттого всё и выглядело
   собранным вручную.
2. **Текст на одной вертикали.** Заголовок секции выравнивается по тексту
   ВНУТРИ карточки (20 + 20 = 40), а не по её краю — как в сгруппированных
   списках iOS.
3. **Над и под одинаково.** У заголовка секции, у ряда вкладок, у ряда пилюль
   отступ сверху равен отступу снизу.
4. Отступы внутри компонента (иконка↔текст, чип↔чип) — `space.sm` (8) или
   `space.xs` (4), тоже из шкалы.

## Источники

- Material 3 — Spacing: 8dp-шкала, 16dp поля контента.
- Apple HIG — Layout: кратность 8, боковые поля 16pt на телефоне.
- В нашем случае поля 20, потому что так нарисовано в Figma.
